Jak Grać

Tap a bottle, then tap an empty bottle or one with the same color on top to pour. Sort the jelly so each filled bottle contains only one color. Use Undo, Restart, a hint, or an extra bottle if you get stuck. On desktop you can also use arrow keys to focus controls and Space to select or pour.
