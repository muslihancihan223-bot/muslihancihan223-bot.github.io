Как Играть

PC Controls WASD / arrow keys = move Space = jump Move mouse = camera rotation Tab = show / hide mouse cursor Left-click = interact with the in-game buttons M = open map Q, E, F = get the power up (by watching a rewarded ad) P = pets menu L = location menu N = Settings menu Mobile Controls Left joystick = move Jump button = jump Move your finger on the right area = camera rotation
