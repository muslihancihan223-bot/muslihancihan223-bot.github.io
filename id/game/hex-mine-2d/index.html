Hex Mine 2D adalah game Puzzle, Sudoku, Asah Otak gratis. Tanpa unduh dan tanpa daftar — langsung main di browser HP, tablet, atau komputer.

Cara Bermain

Your goal is to correctly mark every orange hexagon as either blue or black. A number inside a dark clue cell shows how many adjacent cells are blue. Use the clues together to identify the correct state of each orange cell. Mark all required blue cells and eliminate the remaining cells as black. Complete the puzzle when no orange cells remain. Controls Desktop Left-click: Mark a cell blue Right-click: Mark a cell black Click the same cell again: Undo that mark U or Ctrl + Z: Undo R: Restart H: Hint Esc: Pause Mobile Tap: Mark a cell blue Long-press: Mark a cell black Some versions may also include separate Blue and Black selection buttons. Clue Examples 0: None of the neighboring cells are blue. 6: All six neighboring cells are blue. 3: Exactly three neighboring cells are blue. Special clue symbols may indicate that blue cells must be consecutive, separated, or located along a specific direction. Use deduction, compare overlapping clues, and solve every board without guessing.
