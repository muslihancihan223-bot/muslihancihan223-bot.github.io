Jugar Home Rush

Home Rush es un juego gratis de Puzles. Sin descargas ni registro: juega al instante en el navegador de tu móvil, tablet u ordenador.

Puzles

Cómo Jugar

The goal of the game is to bring the child home to the arms of a loving family! 1. Click on mom or dad to start drawing lines. 2. Draw a line from the parent to the baby of the same color. 3. Be careful when drawing a line - avoid walls, dogs, cars and thieves. 4. Don't let the parents run into each other. 5. Make sure all the children get home safely. Save the kids right now!
