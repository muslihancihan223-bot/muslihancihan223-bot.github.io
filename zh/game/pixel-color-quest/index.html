畅玩 Pixel Color Quest

《Pixel Color Quest》是一款免费的休闲游戏。无需下载和注册，在手机、平板或电脑浏览器中即可立即畅玩。

玩法说明

Goal: completely color the selected picture. Find the number inside a cell, choose the color with the same number, and fill every matching cell. The picture is complete when every section has the correct color. Desktop: - Left mouse button — select a picture or color. - Left mouse button on a cell — fill it with the selected color. Phone and tablet: - Tap a picture or color to select it. - Tap the required cell to fill it.
