Come Giocare

💻 Desktop (Keyboard): W / Up Arrow: Accelerate / Gas S / Down Arrow: Reverse / Brake A / Left Arrow: Tilt truck backwards (balance in mid-air / pull wheelies) D / Right Arrow: Tilt truck forwards (balance in mid-air / stick nose landings) Spacebar / Shift: Activate Nitro Boost 🚀 📱 Mobile / Touchscreen: Tap the on-screen Pedals to accelerate and brake. Use the Left / Right Tilt Buttons while airborne to balance the chassis and land cleanly on all four wheels. Tap the Nitro Icon for an explosive speed burst.
