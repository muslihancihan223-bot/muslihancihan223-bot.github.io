How to Play

The goal: to collect the last trophy. Control: WASD - movement. Space bar - jump. TAB - pause. Shift - cursor. Mouse wheel - zoom in/out.

About the Game

Parkour-based game. The nickname of the best player is shown to everyone at the start - beat the game and your nickname will be displayed too. Change skins to easily tell players apart. And check where each portal leads ;) Colorful skins and different character models. Pets (cats, sheep, dragons... they count as pets, right?) If the game feels too hard, activate a boost like double jump or others to pass difficult sections. Checkpoints are not saved - each run must start from the beginning so speed times are fair for all players.
