How to Play

1. Pick a level from the list or start with the daily crossword. 2. Read the clue — it corresponds to one word in the grid. 3. Type the answer letter by letter into the empty cells. Words cross each other, so every solved word helps with the rest. 4. If you're stuck, use a hint to reveal one letter. 5. Return to unfinished levels anytime — progress saves automatically. 6. Every solved word earns you points that climb the leaderboard and rank you against other players. 7. Unlock collection items and complete quests for bonus rewards.
