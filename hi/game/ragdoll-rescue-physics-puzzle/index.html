कैसे खेलें

Mouse & Touch Controls: • Left Click / Tap: Select and place items from the palette • Drag & Drop: Move placed objects freely across the arena • Widget (↺ / ↻ buttons): Rotate active object to adjust angles • Trash Button (🗑️ DEL): Remove selected item • Right Click (PC): Quick delete object under cursor • Mouse Wheel / Swipe: Pan and scroll camera up/down Keyboard Shortcuts (PC): • Q / E or A / D: Rotate object left / right • 1 – 9: Quick select items from the palette • Spacebar: Start / Resume physics simulation • Delete / Backspace: Delete active item
