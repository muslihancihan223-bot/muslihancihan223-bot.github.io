Comment Jouer

Select a Nut: Click on the bolt you want to take the nut from. Move it: Click on another bolt to move the selected nut there. Sort by Color: Match nuts of the same color on one bolt. Make sure there's enough room on the bolt! Use Tools: Use bonuses if you need to add a bolt, cancel a move, or restart the level. The goal is to clear the board by sorting all the nuts by color.
